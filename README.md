# د. علاء محفوظ - استشاري جراحة الأورام والمناظير

أستاذ م. جراحة الأورام بالمعهد القومي للأورام - جامعة القاهرة، واستشاري جراحات الأورام المتقدمة والمناظير وتدخلات أورام الثدي والجهاز الهضمي والأنف والأذن والحنجرة.

## التخصصات والخبرات الطبية
* جراحات أورام الثدي التحفظية والتجميلية.
* استئصال أورام الجهاز الهضمي والقولون بالمناظير.
* جراحات أورام الرأس والرقبة والدرقية.
* تقديم الاستشارات الطبية وخطة العلاج المتكاملة لمرضى الأورام.
